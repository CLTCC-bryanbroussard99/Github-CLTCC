What is DNS and Why Does It Matter to Analysts?

The Domain Name System (DNS) serves as the internet's directory, translating human-readable hostnames (such as example.com) into numerical IP addresses required to route network traffic.

The "So What?" for Cybersecurity

Default DNS resolvers provided by Internet Service Providers (ISPs) typically perform basic resolution without threat inspection. By implementing filtering public DNS resolvers across workstations or perimeter firewalls, security analysts can block malicious domains, phishing infrastructure, tracking mechanisms, and inappropriate content before initial network connection attempts succeed.

SOC Analyst Key Takeaway: Threat Hunting & Telemetry

Over 90% of malware uses DNS to establish Command and Control (C2) channels, exfiltrate data via DNS tunneling, or dynamically locate infrastructure. Analyzing DNS logs allows SOC analysts to detect early-stage compromises before payloads execute on host systems.

Configuring Custom DNS on a Home Router

Changing DNS settings directly on your home gateway or Wi-Fi router applies DNS-level threat filtering network-wide to every connected endpoint (computers, mobile devices, smart TVs, and IoT hardware) without requiring individual device configuration.

  • Generalized Configuration Workflow

    1. Access the Administrative Console: Open a browser and enter your router's local gateway IP address (commonly 192.168.1.1 or 192.168.0.1). Log in using your administrator credentials.
    2. Locate DNS / WAN Settings: Navigate to the network configuration section (typically labeled Network, Internet, WAN, or DHCP Server Settings).
    3. Switch DNS Assignment to Manual: Change DNS assignment mode from "Automatic / Get from ISP" to "Manual" or "Static".
    4. Enter Resolver Addresses: Input your chosen provider’s IP addresses into the Primary (Preferred) DNS and Secondary (Alternate) DNS fields (e.g., Quad9: 9.9.9.9 and 149.112.112.112).
    5. Save and Flush Client Cache: Apply changes and reboot the router. On endpoints, clear local DNS caches
      • Windows: ipconfig /flushdns
      • Linux/macOS: restart the DNS resolver daemon or reboot).
      • Modern Systems (systemd-resolved)
        • Ubuntu 22.04+ and newer distributions: Run sudo resolvectl flush-caches
        • Older systemd versions: Run sudo systemd-resolve --flush-caches
      • Alternative DNS Services
        • Name Service Cache Daemon (nscd): Run sudo systemctl restart nscd
        • Dnsmasq: Run sudo systemctl restart dnsmasq
        • BIND: Run sudo systemctl restart named or sudo rndc restart

Lab Prep: Essential DNS Protocols & CLI Tools

Encrypted DNS Protocols

  • DoH (DNS over HTTPS): Port 443
  • DoT (DNS over TLS): Port 853
  • Standard Unencrypted DNS: UDP/TCP Port 53

Key Analysis Tools

  • nslookup <domain> <server-IP> (Windows/Linux)
  • dig @<server-IP> <domain> (Linux/macOS)
  • Wireshark (Packet Capture & Protocol Analysis)
