🔬 Wireshark Lab: Encapsulation & Decapsulation

In this lab, students will observe how network messages are encapsulated when sent and decapsulated when received, using the packet analysis tool Wireshark.

🎯 Lab Objectives

✔ Capture live network traffic using Wireshark ✔ Identify encapsulation layers within a packet ✔ Explain how decapsulation occurs at the destination ✔ Connect packet structure to cybersecurity monitoring

🎓 CompTIA Alignment

Network+ (N10-008)

✔ 1.1 – OSI and TCP/IP models ✔ 1.2 – Packet structure and encapsulation ✔ 5.2 – Network troubleshooting tools

Security+

✔ 2.1 – Network security fundamentals ✔ 4.1 – Monitoring and analyzing traffic ✔ 4.3 – Indicators of malicious activity
