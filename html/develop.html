How to Check Your SSD Health Without Third-Party Software

Learn how to leverage native Windows tools to assess Solid State Drive (SSD) health, evaluate SMART metrics, monitor operational status, and check file system integrity.

Instructor Context & Storage Maintenance

Solid State Drives (SSDs) utilize NAND flash memory, which has a finite write endurance based on total bytes written (TBW). Proactively monitoring SSD health using built-in Windows diagnostics ensures critical data protection and helps prevent unexpected drive failures without installing unverified third-party software.

01

Check SSD Health in Windows Settings (Windows 11)

Best For: Visual Inspection & Detailed Wear Metrics

  1. Open Settings (Press Win + I).
  2. Navigate to System → Storage → Advanced storage settings → Disks & volumes.
  3. Select your SSD from the list and click Properties.
  4. Under the Drive health section, review metrics:
    • Estimated remaining life: Displays the percentage of write life remaining (e.g., 97%).
    • Available spare: Indicates percentage of reserved flash blocks remaining (e.g., 100%).
    • Drive temperature: Displays live operating temperature in Celsius (if supported by NVMe/SATA controller).
02

Use Command Prompt (Quick WMIC Check)

Best For: Fast Basic Hardware Pass/Fail Status

  1. Open Command Prompt as Administrator.
  2. Execute the WMIC disk check query command:
wmic diskdrive get status

Note: Returning "OK" confirms Windows has not detected major hardware faults, though WMIC does not display granular wear percentages.

03

Use PowerShell (Windows 10 / 11)

Best For: Multi-Drive Auditing & PowerShell Automation

  1. Open PowerShell as Administrator.
  2. Execute the Storage cmdlet to query physical drives:
Get-PhysicalDisk

Examine the output columns:
• HealthStatus: Healthy indicates normal operation. Warning or Unhealthy signals urgent backup needed.
• OperationalStatus: OK confirms active readiness.

04

Check for File System Errors (CHKDSK Scan)

Best For: Online File System Integrity Inspection

  1. Open Command Prompt or PowerShell as Administrator.
  2. Execute the online scan command (Replace C: with target drive letter if necessary):
chkdsk C: /scan

Runs a non-destructive background check to detect NTFS file system inconsistencies or bad sector allocations.

Critical SSD Failure Warning Signs

1. Warning or Unhealthy Status: Indicates drive endurance exhaustion or pending hardware failure.

2. High SSD Operating Temperatures: Sustained temperatures above 70°C under normal use cause thermal throttling and accelerated component degradation.

3. Frequent System Slowdowns: Severe latency spikes during standard file operations often indicate corrupted block read retries.

4. Read/Write Errors & Unexpected Crashes: File corruption errors or BSODs when accessing specific file paths point to failing NAND flash sectors.

Pro Tip for SSD Maintenance

While native Windows utilities provide excellent immediate status checks, manufacturer-specific dashboard utilities (e.g., Samsung Magician, Crucial Executive, Western Digital Dashboard) or vendor SMART tools can display specific attributes like total host writes, raw vendor logs, and firmware updates.
