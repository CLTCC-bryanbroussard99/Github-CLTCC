Google Cybersecurity Professional Certificate

Program Pathway & Course Breakdown (132 Total Hours)

Why This Matters ("So What?")

Organizations lose millions of dollars every year to data breaches, ransomware, and misconfigured networks. Completing this 9-course sequence builds the exact hands-on technical skills required for entry-level Security Operations Center (SOC) analyst roles.

You will progress from core security principles to operating system administration, network defense, and automated threat detection using industry-standard tools.

Course 1: Foundations of Cybersecurity (10 Hours)

Explore the daily responsibilities of an entry-level security analyst. You will learn how security teams protect organizational assets using the CIA Triad (Confidentiality, Integrity, and Availability—the core model for keeping data private, accurate, and accessible) and examine how past cyberattacks shaped modern defense strategies.

Course 2: Play It Safe: Manage Security Risks (9 Hours)

Learn how businesses identify, assess, and reduce technical risks before attackers exploit them. You will practice conducting security audits and applying standard industry frameworks like the NIST Cybersecurity Framework (a set of guidelines for managing and reducing organizational security risk) and SIEM (Security Information and Event Management—software that collects and analyzes security alerts in real time).

Course 3: Connect and Protect: Networks and Network Security (12 Hours)

Understand how data travels across local networks and the internet—and how attackers intercept that traffic. You will configure network defenses including firewalls, VPNs (Virtual Private Networks—encrypted tunnels that protect data in transit), and intrusion detection systems to harden network infrastructure against common exploits.

Course 4: Tools of the Trade: Linux and SQL (23 Hours)

Master the command-line environments that power enterprise servers and databases. You will manage file permissions and user accounts using the Bash shell (the primary command-line interface for Linux systems) and query large security logs using SQL (Structured Query Language—the standard language used to search and filter relational databases).

Course 5: Assets, Threats, and Vulnerabilities (19 Hours)

Think like an attacker to defend critical systems. You will classify organizational assets, evaluate software flaws, and defend against social engineering, malware, and credential theft using encryption, hashing, and strict access controls.

Course 6: Sound the Alarm: Detection and Response (17 Hours)

Learn what happens the moment an active breach occurs. You will practice the Incident Response Lifecycle (the structured process of detecting, containing, eradicating, and recovering from a cyberattack) by analyzing network packet captures and triaging alerts inside SIEM dashboards.

Course 7: Automate Cybersecurity Tasks with Python (25 Hours)

Eliminate repetitive manual log reviews by writing custom security scripts. You will use Python (a high-level programming language widely used in security automation) to parse log files, flag suspicious IP addresses, and automatically update access control lists.

Course 8: Put It to Work: Prepare for Cybersecurity Jobs (11 Hours)

Translate your technical lab experience into a job-ready portfolio. You will learn how to classify and escalate real-world security incidents, build a professional resume, and practice answering scenario-based technical interview questions.

Course 9: Accelerate Your Job Search with AI (6 Hours)

Use generative artificial intelligence tools ethically and effectively to streamline your job hunt. You will learn prompt engineering techniques to research employers, tailor cover letters to specific job descriptions, and run mock technical interviews.

Course Pacing & Completion Expectations

This self-paced pathway totals 132 hours of instruction and hands-on labs. Stay consistent with your weekly milestones—all modules and quizzes remain open for completion and retakes until the final term deadline without intermediate late penalties, though incomplete checkpoints will carry temporary zeros until submitted.
