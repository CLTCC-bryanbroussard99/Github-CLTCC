The 7-Layer OSI Model Summary

Layer # Layer Name Description Data Unit Key Protocols Common Devices Example
7 Application Provides the interface between the applications (like web browsers or email clients) and the network. Data **HTTP**, **HTTPS**, **FTP**, **SMTP**, **DNS**, **POP3**, **IMAP** Gateway, PC/Server Software Opening a web browser to view a webpage.
6 Presentation Responsible for data formatting, translation, encryption, and compression so the data can be presented to the Application Layer. Data **SSL/TLS**, **JPEG**, **MPEG**, **ASCII** PC/Server Software, Gateway Encrypting an email before it is sent.
5 Session Manages the establishment, maintenance, and termination of connections (sessions) between applications on different devices. Data **NetBIOS**, **RPC**, **PPTP** PC/Server Software, Gateway Maintaining a continuous connection while transferring a large file.
4 Transport Handles reliable and sequential data delivery between processes on the source and destination hosts. Manages segmentation and reassembly. **Segment** (TCP)
**Datagram** (UDP)		 **TCP**, **UDP**, **SCTP** Firewall, Load Balancer, Gateway Ensuring that all packets arrive and are in the correct order when downloading a file (**TCP**).
3 Network Responsible for logical addressing (IP addressing) and path determination (routing) of data from source to destination across multiple networks. **Packet** **IP**, **ICMP**, **OSPF**, **EIGRP** **Router**, Layer 3 Switch Finding the best route for a data packet to travel from New York to London.
2 Data Link Provides node-to-node data transfer and detects/corrects errors that may occur at the Physical Layer. Uses **MAC addresses**. Divided into LLC and MAC sublayers. **Frame** **Ethernet**, **ARP**, **PPP**, **Wi-Fi** (802.11) **Switch**, Bridge, Network Interface Card (**NIC**) Sending data between two computers on the same **local network segment**.
1 Physical Defines the physical characteristics of the network, including cables, connectors, voltage levels, and timing. It transmits raw bit streams over a physical medium. **Bit** **Cables** (Copper, Fiber), **Radio Waves** **Hub**, Repeater, Cabling, Transceiver Converting a digital **1** or **0** into an electrical pulse or light signal for transmission.
